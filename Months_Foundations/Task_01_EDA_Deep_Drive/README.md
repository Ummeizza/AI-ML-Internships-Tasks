# Task 01 – Exploratory Data Analysis Deep Dive

## Author
Umme Izza

## Overview
This project is part of my AI/ML Internship Task 01. The objective is to perform an in-depth Exploratory Data Analysis (EDA) on the Telco Customer Churn dataset to identify customer segments that are more likely to churn and provide business recommendations.

## Dataset
- Dataset: Telco Customer Churn
- Source: Kaggle

## Objectives
- Perform data cleaning and preprocessing.
- Analyze customer churn using univariate, bivariate, and multivariate analysis.
- Identify important relationships between variables.
- Generate visualizations to support business insights.
- Provide recommendations for improving customer retention.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Results
The analysis shows that customers with month-to-month contracts, shorter tenure, and higher monthly charges are more likely to churn. Long-term contracts are associated with lower churn rates.
